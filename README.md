# MDP Data

موقع لعرض داتا مفلترة لكل براند مانجر / أكونت مانجر، برفعة يومية من ملف Excel.

## الفكرة
- الأدمن بيرفع شيت يوميًا (بيمسح القديم ويستبدله بالجديد).
- **البراند مانجر** يشوف كل صفوف الداتا الخاصة بالبراند بتاعه (العمود الرابع في الشيت).
- **الأكونت مانجر** يشوف كل صفوف الداتا الخاصة بالبارتنر بتاعه (العمود التاني في الشيت).
- كل مستخدم يقدر يعمل داونلود لبياناته هو بس كملف Excel.
- الحماية حقيقية على مستوى قاعدة البيانات (Row Level Security) — مش مجرد إخفاء في الواجهة.

---

## الخطوة 1: تجهيز Supabase (قاعدة البيانات + تسجيل الدخول)

1. روح على https://supabase.com واعمل حساب مجاني، وابدأ **New Project**.
2. من داخل المشروع، روح على **SQL Editor** → **New query**.
3. افتح ملف `schema.sql` من المجلد ده، انسخ كل محتواه، الصقه في الـ SQL Editor، واضغط **Run**.
4. روح على **Authentication → Providers → Email**، وشيل تفعيل خاصية **Confirm email** (عشان الحسابات هتتعمل بإيميلات وهمية داخلية وملهاش صندوق بريد حقيقي).
5. روح على **Project Settings → API**، وهتلاقي:
   - **Project URL**
   - **anon public key**

   انسخهم، وحطهم في ملف `config.js` بدل:
   ```js
   const SUPABASE_URL = "PASTE_YOUR_SUPABASE_URL_HERE";
   const SUPABASE_ANON_KEY = "PASTE_YOUR_SUPABASE_ANON_KEY_HERE";
   ```
   (الـ anon key ده مصمم يكون ظاهر في كود الموقع — مش سر، والحماية الحقيقية جايه من الـ RLS اللي عملناه في السكيما.)

## الخطوة 2: عمل حساب الأدمن الأول

صفحة تسجيل الدخول العادية مفيهاش تسجيل حساب جديد (ده مقصود، عشان الحسابات كلها بتتعمل من الأدمن بس). فأول حساب أدمن بتعمله مرة واحدة يدويًا من Supabase مباشرة:

1. روح على **Authentication → Users → Add user** في Supabase.
2. حط الإيميل: `elhalwany@mdp.local`
3. حط كلمة المرور: `Admin123`
4. فعّل خيار **Auto Confirm User** وإنت بتضيفه، واحفظ.
5. ارجع لـ **SQL Editor** وشغّل السطر ده بالظبط:
   ```sql
   update public.profiles set is_admin = true where email = 'elhalwany@mdp.local';
   ```
6. دلوقتي تقدر تدخل على الموقع بـ:
   - اسم المستخدم: `Elhalwany`
   - كلمة المرور: `Admin123`

**عايز تغيّر كلمة المرور دي بنفسك بعدين؟** بعد ما تدخل، هتلاقي رابط **"تغيير كلمة المرور"** في القايمة الجانبية — تحط فيه كلمة مرور جديدة وتحفظها، من غير ما ترجع لـ Supabase تاني.

## الخطوة 3: رفع المشروع على GitHub

المشروع اتجهز بالفعل كـ git repo محلي (فيه commit أول). عشان ترفعه:

1. روح على https://github.com واعمل **New repository** (مثلاً اسمه `mdp-data`) — سيبه **Public** أو **Private** حسب رغبتك، من غير ما تضيف README أو .gitignore من جوجل (المشروع عنده بالفعل).
2. بعد ما تعمل الريبو، هيديك أوامر زي دي (استخدم اللي هو `push an existing repository`):
   ```bash
   cd مسار-مجلد-المشروع
   git remote add origin https://github.com/USERNAME/mdp-data.git
   git branch -M main
   git push -u origin main
   ```
3. لو مش عندك git على جهازك، ممكن ترفع الملفات يدويًا من واجهة GitHub نفسها (Add file → Upload files) واختار كل الملفات.

⚠️ **مهم**: `config.js` فيه مفاتيح Supabase بتاعتك. الـ anon key آمن الظهور (زي ما شرحنا فوق)، لكن لو مشروعك Private مفيهاش مشكلة أصلًا.

## الخطوة 4: نشر الموقع (Hosting)

بما إن الموقع HTML/CSS/JS بسيط بدون أي عملية بناء (build)، أسهل حل:

**الخيار أ — Vercel أو Netlify (الأسرع):**
1. اعمل حساب مجاني على https://vercel.com أو https://netlify.com بحساب GitHub بتاعك.
2. اختار **Import project** واختار الريبو `mdp-data`.
3. سيب كل الإعدادات زي ما هي (مفيش build command مطلوب) واضغط Deploy.
4. هيديك رابط جاهز للموقع فورًا.

**الخيار ب — GitHub Pages (مجاني برضو):**
1. من داخل الريبو على GitHub، روح **Settings → Pages**.
2. تحت **Source** اختار **Deploy from a branch**، وبعدين `main` والمجلد `/ (root)`.
3. احفظ، وهتلاقي رابط الموقع بعد دقيقة أو اتنين.

## الاستخدام اليومي

1. سجّل دخول كـ أدمن — هتوصل لصفحة **رفع الداتا** أول حاجة.
2. من رابط **البراندات والبارتنرز** في القايمة الجانبية: أضف أسماء البراندات والبارتنرز الموجودة عندك (مرة واحدة، وبعدين تزود عليها وقت ما يستجد حاجة).
3. من رابط **المستخدمين والصلاحيات**: أنشئ حساب لكل براند مانجر / أكونت مانجر، وحدد له من نافذة "إدارة الصلاحيات" البراند أو البارتنر (أو أكتر من واحد) اللي يشوفه.
4. من رابط **رفع الداتا**: كل يوم، ارفع ملف الإكسيل (31 عمود، البارتنر في التاني والبراند في الرابع) واضغط تأكيد الرفع — هيمسح القديم ويحط الجديد تلقائيًا.
5. كل مستخدم هيدخل بيوزره وباسوورده ويشوف بياناته بس (بدون أي بحث أو وصول لحاجة تانية)، ويقدر يعمل داونلود ليها.

## بنية الملفات

```
mdp-data/
├── index.html       صفحة تسجيل الدخول
├── dashboard.html    صفحة البراند/أكونت مانجر (عرض + داونلود، بدون بحث)
├── admin.html         لوحة الأدمن — رفع الداتا اليومية
├── brands.html        لوحة الأدمن — إدارة قوائم البراندات والبارتنرز
├── users.html          لوحة الأدمن — المستخدمين والصلاحيات
├── profile.html        تغيير كلمة المرور (لأي مستخدم مسجل دخول)
├── style.css         التصميم العام
├── config.js         بيانات الاتصال بـ Supabase (لازم تعبيها)
└── schema.sql         كود قاعدة البيانات (تشغّله مرة واحدة بس في Supabase)
```
